# تدقيق الواجهة وإمكانية الوصول — UI & Accessibility Audit

التاريخ: 2026-11-01 · المنهج: قياس فعلي من الواجهة الحية (نِسَب WCAG محسوبة برمجيًا) + فحص aria/لوحة مفاتيح.

## 1. تباين الألوان (WCAG 2.1) — ✅ ناجح بالكامل
مقاس على العناصر الحقيقية في الوضعين:

| العنصر | فاتح | داكن | الحكم |
|--------|------|------|-------|
| النص الرئيسي | 11.95 | 17.20 | AAA |
| نص على خلفية الصفحة | 10.83 | — | AAA |
| رأس الجدول / muted | 5.26–5.80 | 7.82–8.93 | AA/AAA |
| خلية جدول (داكن) | — | 5.26 | AA ✓ |
| زر أساسي | 10.32 | — | AAA |

**لا يوجد أي زوج تحت AA.** (الحد: 4.5 عادي، 3.0 كبير.)

## 2. الشفافية والعتامة
- العناصر التفاعلية تستخدم ألوان صريحة لا opacity منخفضة للنصوص.
- النصوص المخفية تفاعليًا (disabled) وحدها تحت AA — مقبول ومعلَّم بصريًا.

## 3. حالات التركيز — ✅ القواعد موجودة ومُتحقق منها في الحزمة الحية
- قواعد `:focus-visible` عامة + خاصة (أزرار PrimeNG بـ box-shadow) موجودة في CSS المحمّل فعليًا، و`--color-focus` معرّف.
- **ملاحظة منهجية**: أدوات المحاكاة (CDP) لا تُفعّل heuristic المتصفح لـ :focus-visible — التحقق تم على مستوى القواعد المطبقة؛ يُستحسن تمرير يدوي واحد بلوحة المفاتيح في الاستعراض النهائي.

## 4. لوحة المفاتيح — إصلاحات مطبقة
| الفحص | قبل | بعد |
|-------|------|-----|
| رابط "تخطَّ إلى المحتوى" | غير موجود | ✅ أضيف (يظهر عند التركيز فقط) + `main id="main-content" tabindex="-1"` |
| `scope="col"` على رؤوس الجداول | مفقود | ✅ أضيف على كل الجداول عبر DataTable |
| `aria-sort` على العمود المفرز | مفقود | ✅ أضيف (ascending/descending/none) |
| aria-label لحقل البحث | placeholder فقط | ✅ أضيف |

## 5. aria ودلائل المعالم — ✅
- `nav[aria-label]` ✓، `main` ✓، `lang="ar"` و`dir="rtl"` ✓.
- 8/8 أزرار أيقونية عليها aria-label/title ✓.
- 6/6 أيقونات SVG `aria-hidden` ✓.
- الجداول عناصر `table/th/td` دلالية ✓، والحوارات PrimeNG (role=dialog + focus trap مدمج).

## 6. توصيات متبقية (غير حاجزة)
1. تمرير يدوي واحد بلوحة المفاتيح على المسار: تسجيل دخول ← جدول ← حوار (تأكيد heuristic).
2. حقل البحث حاليًا بدون `<label>` مرئي — aria-label كافٍ، وlabel مخفي اختياري لاحقًا.
3. إضافة `prefers-reduced-motion` بقاعدة عامة (GSAP/الحركات موجودة أصلًا خلف `data-motion`).
