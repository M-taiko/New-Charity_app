# frontend/ — the "Naguib Selim Charity" SPA (Angular 20 + PrimeNG)

A single-page application that rebuilds every screen of the system from scratch — Arabic and RTL-first, with the "Naguib Selim Charity" (مؤسسة نجيب سليم الخيرية) identity: cream paper, brown ink, ruled lines, and status stamps — built from only the eight brand colors, in both light and dark themes. Served by PHP as static files from `../public/app` (see the root `README.md`).

## Commands

```bash
npm run bootstrap     # verify local tooling
npm start             # dev server on :4200 (proxies /api to PHP at 127.0.0.1:8000)
npm run build         # production build into dist/app
npm run icons         # regenerate the Tabler icon sprite
npm run fonts         # subset fonts (pyftsubset — requires fonttools+brotli)
npm run lint          # ESLint (TS rules + templates)
npm run lint:styles   # Stylelint (BEM + browser support)
npm run check:i18n    # no Arabic text outside ar.json, no missing keys
npm run pack          # copy the build to ../public/app (+ .htaccess + checksums)
npm run e2e           # Playwright end-to-end specs
npm test              # unit tests (headless Chrome)
```

## Server deployment

Nothing Node-based runs on the server: `npm run build && npm run pack`, then upload `public/app`. Deep links work through the `/app/{any?}` route in `routes/web.php` (HTML served no-cache, hashed assets cached forever via `.htaccess`).

## Recorded decisions

- **Angular 20.3 + zone.js + OnPush/signals** — zoneless isn't stable in v20.
- **PrimeNG 20** with an Aura-derived preset built only from the eight palette colors.
- **ngx-translate v18** standalone `TranslatePipe`, single `ar.json`.
- **Font weight 500 dropped** to respect the ~220KB font budget (400/600 suffice).
- **Motion**: CSS for the simple cases, GSAP available; Angular animations allowed per owner decision.
- **Icons**: Tabler outline sprite only — the PrimeIcons font is intentionally not installed (docs/dependencies.md).
- One README for this whole folder instead of a README per subfolder (owner decision).
